# ЧТО УЖЕ ИЗВЕСТНО О РЕАЛЬНОМ ГЕЙТЕ

При нажатии платной функции приложение отправляет:

```http
POST /np/member/rest/interface?timestamp=1793029882000&flag=ff3876048fc988c32351eec2fa62300
Host: normalplayer.top
Content-Type: text/plain; charset=utf-8
User-Agent: okhttp/4.9.0
```

Тело запроса:

- шифрованное;
- base64;
- примерно 1.7 КБ;
- не читать и не изменять;
- `flag` является MD5-подписью запроса;
- приватного ключа нет;
- подделка запроса не является целью.

Сервер отвечает открытым JSON:

```json
{
  "code": 6,
  "message": "该功能仅捐赠用户可用！可前往用户信息进行捐赠~\n\nThis feature is only available for donation users!"
}
```

Критический вывод:

- сервер не возвращает зашифрованный результат операции;
- сервер возвращает статус/решение;
- локальный клиент интерпретирует поле `code`;
- это entitlement-interpreter;
- цель — перехватить интерпретацию ответа на стороне клиента;
- запрос не менять;
- тело запроса не менять;
- MITM не нужен для первого подхода.

В оффлайн-режиме операция получает сетевое исключение, которое преобразуется в отказ «ошибка подключения». Поэтому нужно патчить две точки:

1. обработку `code: 6`;
2. обработку IOException/таймаута/сетевого отказа.

Оффлайн-патч считается успешным только если платная операция реально выполняется в авиарежиме без:

- диалога доната;
- сообщения «только для донатеров»;
- сообщения «ошибка подключения».
